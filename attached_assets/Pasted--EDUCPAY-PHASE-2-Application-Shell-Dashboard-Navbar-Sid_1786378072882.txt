# EDUCPAY — PHASE 2

## Application Shell — Dashboard, Navbar, Sidebar, Navigation et Responsive

Tu es un **Senior Frontend Architect / Full-Stack Engineer spécialisé dans les applications SaaS modernes**, avec une forte expérience en Next.js, React, TypeScript, UX/UI, design systems, responsive design et architectures frontend évolutives.

Tu travailles sur **EducPAY**, un SaaS de gestion de scolarité et de paiements destiné aux établissements scolaires publics.

La **Phase 1 est déjà en ligne sur Vercel et a été validée**. Cette Phase 2 s’inscrit donc directement dans la continuité de cette version déployée, afin d’être intégrée proprement et prise en charge sans rupture par Vercel.

Cette phase correspond **UNIQUEMENT À LA PHASE 2**.

---

# 1. CONTEXTE DU PROJET

EducPAY est un SaaS multi-établissement destiné à la gestion de la scolarité.

Le produit permettra progressivement de gérer :

* établissements ;
* années scolaires ;
* classes ;
* élèves ;
* inscriptions ;
* parents ;
* frais mensuels ;
* frais supplémentaires ;
* paiements ;
* paiements partiels ;
* reçus ;
* rapports ;
* portail parent ;
* application mobile ;
* abonnements SaaS.

Les principaux rôles prévus sont :

```text
SUPER_ADMIN
DIRECTOR
ACCOUNTANT
PARENT
```

### Règles métier déjà validées

* L'élève n'a pas de compte.
* Le parent possède un compte.
* Un parent peut avoir plusieurs enfants dans son établissement.
* Dans la V1, le compte parent est lié à un seul établissement.
* Les paiements sont actuellement uniquement en espèces.
* Les paiements partiels sont autorisés.
* Les frais peuvent être mensuels ou supplémentaires.
* Les établissements souscrivent à EducPAY via un abonnement mensuel ou annuel.
