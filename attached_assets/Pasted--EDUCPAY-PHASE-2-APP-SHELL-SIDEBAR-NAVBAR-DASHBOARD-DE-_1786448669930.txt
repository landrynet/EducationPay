# 3. CORRECTION OBLIGATOIRE DE VERCEL

Il existe actuellement cette erreur lors du déploiement Vercel :

```text
No Output Directory named "public" found after the Build completed.

Configure the Output Directory in your Project Settings.

Alternatively, configure vercel.json#outputDirectory.
```

### Cette erreur doit être corrigée dans cette phase.

Mais attention :

**Ne fais pas simplement une modification arbitraire de Vercel pour faire disparaître l'erreur.**

Commence par identifier :

* framework utilisé ;
* commande de build ;
* dossier réellement généré après le build ;
* configuration Vercel actuelle ;
* `vercel.json` s'il existe ;
* `package.json` ;
* éventuelle configuration du framework.

Détermine pourquoi Vercel cherche un dossier :

```text
public
```

alors que le build génère probablement un autre dossier ou utilise un framework qui gère automatiquement son output.

### Objectif

Configurer Vercel **correctement pour le framework utilisé**.

Ne jamais créer un faux dossier `public` uniquement pour satisfaire Vercel.

Ne jamais copier les fichiers build dans `public` comme hack.

Ne jamais utiliser une solution temporaire.

---

# 4. VÉRIFICATION DU BUILD

Avant de corriger Vercel, exécuter le build localement.

Identifier précisément :

```text
Build command
Output directory
Framework
Node version
Package manager
```

Puis vérifier le résultat réel du build.

La configuration Vercel doit correspondre à ce résultat.

### Si le framework gère automatiquement son output

Laisser Vercel utiliser la configuration native du framework lorsque cela est approprié.

### Si un `outputDirectory` est réellement nécessaire

Configurer le vrai dossier généré.

Ne jamais mettre :

```text
public
```

simplement parce que Vercel le demande dans l'erreur.
