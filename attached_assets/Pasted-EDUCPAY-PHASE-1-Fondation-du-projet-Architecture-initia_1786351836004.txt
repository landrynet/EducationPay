1. CONTEXTE DU PRODUIT

EducPAY est un SaaS multi-établissement destiné à la gestion de la scolarité.

Le produit permettra notamment :

- gérer plusieurs établissements ;
- gérer les années scolaires ;
- gérer les classes ;
- gérer les élèves ;
- gérer les parents ;
- gérer les frais scolaires ;
- gérer les frais mensuels ;
- gérer les frais supplémentaires ;
- enregistrer les paiements en espèces ;
- gérer les paiements partiels ;
- générer des reçus ;
- permettre aux parents de consulter la situation financière de leurs enfants ;
- fournir un portail Web ;
- fournir ultérieurement une application mobile Expo ;
- gérer les abonnements SaaS des établissements.

Règles métier déjà validées

Élève

- L’élève n’a PAS de compte utilisateur.
- L’élève est une entité métier.
- Il est lié à un ou plusieurs parents/tuteurs.
- Son historique d’inscription doit être conservé.

Parent

- Le parent possède un compte.
- Le compte parent appartient à un établissement.
- Un parent peut avoir plusieurs enfants dans cet établissement.
- Dans la V1, un compte parent n’est pas global à plusieurs établissements.
- Si le même parent a un enfant dans un autre établissement utilisant EducPAY, il aura actuellement un compte distinct pour cet autre établissement.

Frais

EducPAY doit gérer notamment :

- frais mensuels ;
- frais d’inscription ;
- frais d’examen ;
- autres frais supplémentaires.

Les paiements peuvent être partiels.

Paiement

Pour la V1 :

- paiement uniquement en espèces ;
- pas de paiement en ligne ;
- paiement partiel autorisé.

Utilisateurs

Les principaux rôles prévus sont :

- SUPER_ADMIN ;
- DIRECTOR ;
- ACCOUNTANT ;
- PARENT.
